# gaseo (가세오)

<p align="center">
  <img src="assets/gaseo-hero-01.png" alt="가세오" width="320">
</p>

> **지금 이 세션, 파세오로 가세오 — 거기서 이어서 하면 됩니다.**

[Paseo](https://paseo.app)는 자기가 띄운 에이전트만 목록에 보여줍니다. 터미널에서 `claude`로 직접 연 세션은 아예 뜨지 않고, 앱에서 이어받을 방법도 없습니다. `가세오`가 그 구멍을 메웁니다. "가세오" 한마디면 지금 이 순간 나누고 있는 대화가 원래 제목 그대로 파세오에 나타나고, 바로 이어서 말을 걸 수 있습니다.

## 빠른 시작

### 1. 마켓플레이스 추가

```
/plugin marketplace add https://github.com/fivetaku/gptaku_plugins.git
```

### 2. 설치

```
/plugin install gaseo
```

### 3. Claude Code 재시작

(새 커맨드는 재시작해야 등록됩니다.)

### 4. 실행

```
/gaseo
```

끝입니다. 지금 있는 세션이 파세오에 들어갔습니다. 앱을 열고 이어서 대화하세요.

이 폴더의 지난 대화를 가져오려면:

```
/gaseo past
```

말로 해도 됩니다:

- "파세오로 가세오"
- "이 세션 파세오로 가세오"
- "가세오 해줘"
- "파세오에 등록해줘"
- "과거 세션 파세오로 가져와줘"

---

## 왜 가세오인가

**터미널 세션은 파세오에 보이지 않습니다.** 파세오 목록에 뜨는 건 파세오가 직접 띄운 에이전트뿐입니다. 셸에서 직접 돌린 것들 — 사실상 실제 작업의 대부분 — 은 목록에 없고, UI에는 가져오기 버튼조차 없습니다.

**복사가 아니라 연결입니다.** `가세오`는 `paseo import`를 부르고, 이건 세션 ID를 가리키는 포인터 하나만 남깁니다. 대화 기록은 Claude Code가 둔 자리에 그대로 있습니다. 나중에 파세오에서 에이전트를 아카이브해도 원본 대화는 멀쩡합니다.

**작업 중에 자리를 떠도 됩니다.** 세션을 등록해두고 노트북을 덮은 뒤, 파세오 앱에서 이어가면 됩니다. 같은 대화, 같은 기록이라 상황을 다시 설명할 필요가 없습니다.

**두 번 등록되지 않습니다.** 파세오가 이미 알고 있는 세션 — 파세오가 띄운 것 포함 — 은 감지해서 건너뜁니다.

**파세오가 모르는 폴더도 됩니다.** import 시점에 워크스페이스가 자동으로 만들어집니다.

---

## 작동 방식

```
/gaseo
  → 이 폴더의 세션 디렉토리를 찾는다
      ~/.claude/projects/<절대경로의 비영숫자를 '-'로 치환>/
  → $CLAUDE_CODE_SESSION_ID의 기록이 여기 있으면 그것, 없으면 최신 .jsonl
  → 이미 ~/.paseo/agents에 있나? → 건너뛰고 보고, 종료
  → paseo import <세션ID> --provider claude --cwd <폴더>
  → 원래 대화 제목 그대로 파세오에 등장
```

파세오는 대화를 자체적으로 저장하지 않습니다. 에이전트 기록마다 Claude 세션 ID를 가리키는 `persistence.nativeHandle` 포인터만 들어 있습니다. import가 즉시 끝나고, 데몬 재시작이 필요 없고, 데이터가 절대 중복되지 않는 이유가 여기 있습니다.

## 주요 기능

| 기능 | 설명 |
|------|------|
| 현재 세션 등록 | `/gaseo` — 지금 대화 중인 세션을 알아서 잡습니다. ID 입력 불필요 |
| 과거 세션 선택 | `/gaseo past` — 첫 메시지·시각·등록 여부까지 붙은 목록에서 고릅니다 |
| 중복 방지 | 이미 등록된 세션은 다시 넣지 않고 그 사실을 알려줍니다 |
| 새 워크스페이스 | 파세오가 처음 보는 폴더도 워크스페이스를 만들며 등록합니다 |
| 복사 아닌 연결 | 원본 대화 기록을 옮기거나 고치거나 복제하지 않습니다 |
| 감지 결과 확인 | 어떤 세션을 잡았는지 첫 메시지를 보여준 뒤 진행합니다 |

## 명령어

| 명령어 | 설명 |
|--------|------|
| `/gaseo` | 현재 세션 등록 |
| `/gaseo past` | 이 폴더의 과거 세션 목록에서 골라 등록 |
| `/gaseo <폴더>` | 다른 폴더의 현재 세션 등록 |
| `/gaseo past <폴더>` | 다른 폴더의 과거 세션 선택 |

### 자연어 트리거

- `/gaseo`, "파세오로 가세오", "이 세션 파세오로 가세오", "가세오 해줘", "파세오에 등록해줘"
- "과거 세션 파세오로 가져와줘", "지난 대화 파세오에 추가해줘"
- "register this session to paseo", "send this session to paseo"
- "import my past sessions into paseo"

## 알아둘 점

**현재 세션을 어떻게 찾는가.** `가세오`는 Claude Code가 살아 있는 세션에 대해 내보내는 `$CLAUDE_CODE_SESSION_ID`를 읽고, 그 대화 기록이 해당 폴더에 실제로 있는지 확인합니다. 이게 없을 때만 가장 최근에 기록된 대화를 고르는 방식으로 물러섭니다 — 이건 추측입니다. 백그라운드 서브에이전트나 훅이 띄운 세션도 같은 디렉토리에 기록을 남기고, 그쪽이 더 최신인 경우가 잦기 때문입니다. 출력에 어느 경로를 썼는지(`via=env` / `via=mtime`)가 표시되니, `via=mtime` 추측일 때는 같이 뜨는 첫 메시지를 확인하거나 `/gaseo past`로 직접 고르세요.

**Claude 세션 전용입니다.** codex 세션은 폴더가 아니라 날짜 기준으로 저장돼서, 이 플러그인이 쓰는 폴더→세션 매핑이 아직 적용되지 않습니다.

**데몬을 대신 재시작하지 않습니다.** 데몬이 죽어 `paseo import`가 실패하면 상황만 보고하고 멈춥니다. 재시작은 돌아가는 에이전트를 전부 죽이므로, 그 판단은 사용자 몫으로 남깁니다.
