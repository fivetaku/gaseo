# gaseo (가세오)

<p align="center">
  <img src="assets/gaseo-hero-01.png" alt="gaseo" width="320">
</p>

> **いま話しているそのセッションを、Paseo へ送る。続きは向こうで。**

[Paseo](https://paseo.app) の一覧に並ぶのは、Paseo 自身が起動したエージェントだけです。ターミナルで `claude` と打って始めたセッションは表示されず、アプリから再開する手段もありません。`gaseo` はその穴を埋めます。「가세오」と言えば、いままさに交わしている会話が元のタイトルのまま Paseo に現れ、そのまま続けられます。

## クイックスタート

### 1. マーケットプレイスを追加

```
/plugin marketplace add https://github.com/fivetaku/gptaku_plugins.git
```

### 2. インストール

```
/plugin install gaseo
```

### 3. Claude Code を再起動

（新しいコマンドは再起動後に登録されます。）

### 4. 実行

```
/gaseo
```

これだけです。いるセッションが Paseo に入りました。アプリを開いて続きをどうぞ。

このフォルダの過去の会話を取り込むなら:

```
/gaseo past
```

話しかけても動きます:

- 「이 세션 파세오로 가세오」
- 「가세오 해줘」
- "register this session to paseo"
- "import my past sessions into paseo"

## なぜ gaseo か

**ターミナルのセッションは Paseo から見えません。** Paseo が一覧に出すのは自分で起動したエージェントだけ。シェルから自分で走らせたもの — 実作業のほとんど — は一覧になく、UI にインポートのボタンもありません。

**コピーではなくリンクです。** `gaseo` が呼ぶ `paseo import` は、セッション ID を指すポインタを一つ書くだけ。会話ログは Claude Code が置いた場所にそのまま残ります。あとで Paseo 側でアーカイブしても、元の会話は無傷です。

**作業の途中で席を立てます。** セッションを登録してノートを閉じ、Paseo アプリから続ける。同じ会話・同じ履歴なので、状況を説明し直す必要はありません。

**二重登録されません。** Paseo が既に知っているセッション（Paseo が起動したものを含む）は検出してスキップします。

**Paseo が知らないフォルダでも大丈夫。** インポート時にワークスペースが自動生成されます。

## 仕組み

```
/gaseo
  → このフォルダのセッションディレクトリを探す
      ~/.claude/projects/<絶対パスの英数字以外を '-' に置換>/
  → $CLAUDE_CODE_SESSION_ID の記録がここにあればそれ、無ければ最新の .jsonl
  → すでに ~/.paseo/agents にある? → スキップして報告、終了
  → paseo import <セッションID> --provider claude --cwd <フォルダ>
  → 元のタイトルのまま Paseo に登場
```

Paseo は会話そのものを保存しません。各エージェントのレコードが持つのは Claude セッション ID を指す `persistence.nativeHandle` ポインタだけ。インポートが一瞬で終わり、デーモンの再起動も要らず、データが重複しない理由はここにあります。

## 主な機能

| 機能 | 説明 |
|------|------|
| 現在セッションの登録 | `/gaseo` — いま話しているセッションを自動で特定。ID 入力は不要 |
| 過去セッションの選択 | `/gaseo past` — 最初のメッセージ・時刻・登録状況つきの一覧から選ぶ |
| 重複防止 | 登録済みのセッションは再取り込みせず、その旨を報告 |
| 新規ワークスペース | Paseo が初めて見るフォルダにもワークスペースを作って登録 |
| コピーではなくリンク | 元の会話ログを移動・改変・複製しない |
| 検出結果の確認 | どのセッションを掴んだかを最初のメッセージで提示してから進む |

## コマンド

| コマンド | 説明 |
|----------|------|
| `/gaseo` | 現在のセッションを登録 |
| `/gaseo past` | このフォルダの過去セッションから選んで登録 |
| `/gaseo <フォルダ>` | 別フォルダの現在セッションを登録 |
| `/gaseo past <フォルダ>` | 別フォルダの過去セッションを選択 |

## 注意点

**現在のセッションをどう特定するか。** `gaseo` は Claude Code が稼働中セッションについて公開する `$CLAUDE_CODE_SESSION_ID` を読み、その会話ログが対象フォルダに実在するかを確認します。それが使えない場合にのみ、最後に書き込まれた会話を選ぶ方式にフォールバックします — これは推測です。バックグラウンドのサブエージェントやフックが起動したセッションも同じディレクトリに記録を残し、そちらの方が新しいことが多いためです。出力にはどちらの経路を使ったか（`via=env` / `via=mtime`）が示されます。`via=mtime` の推測なら、併記される最初のメッセージを確認するか、`/gaseo past` で明示的に選んでください。

**Claude セッション専用です。** codex のセッションはフォルダではなく日付で保存されるため、このプラグインが使うフォルダ→セッションの対応付けはまだ適用できません。

**デーモンを勝手に再起動しません。** デーモンが落ちて `paseo import` が失敗した場合、状況を報告して止まります。再起動は稼働中のエージェントを全て落とすため、その判断は利用者に委ねます。

## 必要環境

- [Claude Code](https://docs.anthropic.com/claude-code) CLI
- [Paseo](https://paseo.app) がインストール済みで、デーモンが稼働中（`paseo status` で確認）
- `paseo` CLI が `PATH` 上、または既定のインストール先にあること
